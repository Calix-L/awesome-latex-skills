The five [skills](../README.md#skills) provide agent workflows and references.
The CLI exports, checks and records evidence; it does not perform model editing
by itself. Native tools and human review remain separate from source-byte checks.

五个 [Skill](../README_CN.md#skills) 提供 Agent 工作流和参考文件。CLI 导出、检查
和记录证据，本身不调用模型编辑论文。本地工具和人工审查不能由字节核验代替。
